# Сценарий демо-видео для TikTok

Цель: за 60–90 секунд показать ревьюеру полный путь «авторизация → загрузка →
результат» в реальном приложении.

## Вариант A. Автоматическая запись (быстро)

```bash
# 1. Тестовое видео
python3 scripts/make_sample_video.py

# 2. Приложение (демо или реальные ключи)
DEMO_MODE=1 BASE_URL=http://127.0.0.1:8000 python3 run.py

# 3. Запись в другом терминале
python3 scripts/record_demo.py --url http://127.0.0.1:8000
```

Файлы:

- `demo/video/video-scheduler-demo.mp4` — 1280×800/1440×900, ~1 минута;
- `demo/frames/01…06.png` — ключевые кадры.

Для заявки **обязательно** повторите запись на деплое с реальными ключами:

```bash
BASE_URL=https://ДОМЕН DEMO_MODE=0 python3 run.py
python3 scripts/record_demo.py --url https://ДОМЕН
```

Тогда шаг 2 — настоящий экран TikTok, а не локальная демонстрация.

## Вариант B. Ручная запись с телефона

1. Откройте сайт в браузере телефона, включите запись экрана.
2. Нажмите «Подключить TikTok».
3. Покажите экран TikTok: название приложения, scopes, кнопку «Разрешить».
4. Вернитесь в кабинет — виден username.
5. Выберите видео из галереи, введите описание.
6. Нажмите «Загрузить в TikTok», покажите прогресс.
7. Дождитесь статуса «Отправлено в черновики TikTok».
8. Откройте приложение TikTok → Профиль → Черновики, покажите видео.
9. Остановите запись, обрежьте лишнее.

## Что нельзя показывать

- экран с надписью «Демо» вместо реального OAuth (для заявки);
- чужие видео, музыку или аккаунты;
- склейки, скрывающие шаги авторизации;
- ускорение, из-за которого не видно, что видео действительно загрузилось;
- обещания «массового постинга» или обхода ограничений TikTok.

## Технические параметры

- 720p или выше, 16:9 или 9:16;
- MP4/H.264, 24–30 fps;
- до 2 минут;
- без водяных знаков и чужих логотипов;
- имя файла: `video-scheduler-demo.mp4`.

## Быстрая проверка видео

```bash
ffprobe -v error -show_entries format=duration,size \
  -show_entries stream=width,height,codec_name \
  -of default=nw=1 demo/video/video-scheduler-demo.mp4
```

## Если запись через Playwright падает

Playwright скачивает свой Chromium:

```bash
python3 -m playwright install chromium
```

Если в системе несколько сборок, укажите рабочую явно:

```bash
PLAYWRIGHT_CHROMIUM=/путь/к/chrome python3 scripts/record_demo.py
```

Альтернатива — OBS / встроенная запись экрана телефона по варианту B.
