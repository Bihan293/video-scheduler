Что делает приложение

  • авторизует пользователя через TikTok Login Kit и хранит OAuth-токен;
  • принимает видеофайл, описание и настройки приватности;
  • загружает видео через Content Posting API в черновики или публикует его;

  • позволяет отключить аккаунт и удалить сохранённые данные.
